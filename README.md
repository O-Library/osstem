# 오스템문고 — AI 도서 추천·대출 포털

사내 도서관(오스템문고)의 **도서 검색·대출·반납 알림**에 **상황·직무 기반 AI 추천**과 **희망도서 투표**를 더한 포털입니다.
2026 전사 AI 해커톤 출품작입니다.

| 화면 | 주소 |
|---|---|
| 사용자 페이지 | `docs/index.html` → GitHub Pages 루트 |
| 관리자 페이지 | `docs/admin.html` (관리자 비밀번호로 로그인) |

## 해결하려는 문제
- **직원:** 1,000권이 넘는 장서에서 내 상황에 맞는 책을 찾기 어렵습니다. 원하는 책이 대출 중이면 그대로 포기합니다.
- **운영자:** 어떤 책을 사야 할지 근거가 없어 감으로 구매합니다. 구매 요청은 메일로 따로 받아 검토하느라 시간이 듭니다.

## 주요 기능
1. **상황·직무 기반 추천**: 직무 그룹(해커톤 8개 업무 그룹)·고민 상황·관심 키워드를 받으면 보유 도서 중 3권을 골라, 추천 이유와 대출 가능 여부를 보여줍니다.
2. **기존 자동화와 연결**: 실시간 대출 현황을 반영해, 대출 중인 책에는 **지금 빌릴 수 있는 대체 도서**를 함께 추천합니다. 대출 신청·반납 예정 메일 등 기존 기능과 그대로 이어집니다.
3. **운영자 인사이트**: "자주 찾지만 보유하지 않은 주제"를 집계해 구매 우선순위를 제안합니다.
4. **희망도서 신청 → 구매 투표**: 직원이 희망도서를 신청하고 임직원 투표로 구매를 정합니다. 입고되면 신청자에게 자동으로 메일을 보냅니다.

## 개인정보 최소화 설계
- 추천에는 **사번·이름·교육이력을 쓰지 않습니다.** 직무 그룹·고민·키워드만 입력합니다.
- 추천·검색 기록은 **누구인지 알 수 없는 키워드**로만 저장해 구매 인사이트에 씁니다.
- 희망도서 신청과 투표에만 사번으로 본인 확인을 합니다(중복 투표 방지·입고 알림용). 화면에는 신청자를 공개하지 않습니다.

## 구조
```
[GitHub Pages]  docs/index.html (사용자) · docs/admin.html (관리자)
      │  fetch (POST, JSON)
      ▼
[Google Apps Script 웹앱]  추천 엔진 · 대출 로직 · 메일 자동 발송(매일 9시)
      │
      ▼
[Google Sheets]  도서 · 대출 · 예약 · 사원명부 · 검색기록 · 희망도서 · 구매투표
```
- `src/Index.html` 한 벌로 Apps Script 화면과 GitHub Pages 화면을 함께 만듭니다(`node tools/build.js`).
- 서버 주소는 `docs/config.js`의 `API_URL`에 있습니다.
- `docs/config.js`의 `API_MODE`
  - `'demo'`: 실제 장서·대출 현황 스냅샷(2026-10-27)으로 브라우저 안에서 동작합니다. 시연용이며, 다른 이용자 이름은 가명입니다. 관리자 비밀번호는 `demo1234`입니다.
  - `'live'`: Apps Script 웹앱에 연결해 구글 시트를 실시간으로 읽고 씁니다.

## 기대효과
- **대출률 상승:** 상황에 맞는 책을 바로 찾고, 대출 중이면 대체 도서를 안내받습니다.
- **구매 검토 시간 절감:** 신청·투표·검색 수요가 한 화면에 모여 구매 우선순위가 자동으로 나옵니다.
- **확산성:** 8개 업무 그룹 전체가 대상이며, 같은 추천 구조를 사내 교육 콘텐츠 추천으로 확장할 수 있습니다.
